# 🍎 Tracker de Régime - Gwen & Ludo 💪

Application web responsive pour le suivi hebdomadaire des mensurations et menus de Gwen et Ludo.

## 🚀 Fonctionnalités

- **Suivi des mensurations** : Enregistrez poids, tour de taille, hanches et poitrine
- **Graphiques d'évolution** : Visualisez vos progrès avec des graphiques interactifs
- **Planification des menus** : Organisez vos repas par semaine
- **Import/Export JSON** : Sauvegardez et restaurez vos données
- **100% Local** : Toutes les données sont stockées dans votre navigateur
- **Responsive** : Fonctionne sur mobile et desktop

## 💻 Technologies

- React 18
- Vite
- Tailwind CSS
- Recharts
- localStorage

## 🛠️ Installation locale

```bash
# Installer les dépendances
npm install

# Lancer en développement
npm run dev

# Build pour production
npm run build

# Preview du build
npm run preview
```

## 📦 Déploiement

L'application est prête pour être déployée sur :
- Netlify (recommandé)
- Vercel
- GitHub Pages

Pour Netlify, il suffit de connecter ce repo et le déploiement se fera automatiquement.

## 📝 Utilisation

1. **Saisie** : Enregistrez vos mensurations hebdomadaires
2. **Évolution** : Consultez vos graphiques et statistiques
3. **Menus** : Planifiez vos repas de la semaine
4. **Outils** : Exportez/importez vos données, consultez les statistiques

## 💾 Backup des données

⚠️ **Important** : Les données sont stockées localement dans votre navigateur. Pensez à :
- Exporter régulièrement vos données (bouton dans l'onglet Outils)
- Ne pas vider le cache de votre navigateur sans avoir fait de backup
- Conserver vos fichiers JSON d'export en lieu sûr
